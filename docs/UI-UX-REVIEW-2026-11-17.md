# SnipArc 网站 UI/UX 诊断与第一轮改进

后续实施结果见 [第二轮体验改造](UI-UX-IMPLEMENTATION-ROUND-2.md)。下文保留为第一轮诊断记录，下载状态与当前页面结构以第二轮记录和实际源码为准。

日期：2026-11-17。检查依据：当前网站源码、已有截图原图、素材更新记录及生成的静态页面。本轮未重新运行 SnipArc 软件。

## 主要判断

现有页面的问题不是功能太少，而是视觉重点和证据不匹配：首屏同时介绍大量功能，装饰和壁纸占据主要空间，而实际操作界面及使用收益不突出。设计方向是白色主体、浅灰分区、蓝色强调，以真实产品界面和清晰的操作路径建立可信度。

| 优先级 | 发现及证据 | 对体验的影响 | 本轮处理 |
| --- | --- | --- | --- |
| 高 | Hero 同时罗列截图、录屏和 AI；副标题继续堆叠功能 | 新访客需要先理解术语，才能判断是否需要产品 | 中英文改为截图与表达的核心价值；更多能力放到下方任务卡片 |
| 高 | `capture-wide.zh-cn.png` 的裁切漏掉底部工具栏；屏幕外壳和叠加任务栏增加视觉噪声 | 图很大，但产品本身缺乏辨识度 | 使用保留工具栏的原始实机截图，取消中英文首页设备外壳与假任务栏覆盖 |
| 高 | AI 功能区引用的是矩形和箭头标注截图 | 文字与视觉证据不对应 | 分开呈现截图、标注和文字提取，每个模块使用对应真实截图 |
| 高 | 英文首页仍使用旧展示图；实机素材只有中文软件 UI | 容易将概念展示误认为当前实机效果 | 英文也使用真实素材，明确标记 Chinese UI shown，不伪造英文 UI |
| 高 | 信任栏出现 4.9/5、100%、低于 0.1 秒等缺少可靠依据的指标 | 降低可信度，也分散下载路径 | 中英文首页改为中性的功能摘要，不修改其他语言的既有宣传 |
| 高 | 商店地址含 `TBD_SNIPARC_STORE_ID`，但页面仍宣称可以获取 | 点击后无法完成任务 | 中英文首页不再展示未配置的 Store 入口；其他页面仍需单独清理 |
| 中 | Hero 同一个控件 hover 换图、点击又滚动到功能区 | 控件结果不稳定，键盘焦点也会改变图像 | 改为明确的预览按钮，点击仅切图，探索功能使用独立链接 |
| 中 | Hero 文案、设备展示和说明垂直堆叠 | 用户进入页面后难以同时看到定位与产品 | 宽屏采用左文案、右实机图；窄屏依次排列 |
| 中 | 功能行带有非交互箭头，容易被误认成可点击行 | 鼠标和触屏用户产生错误预期 | 本轮中英文首页隐藏装饰箭头，保留清晰列表 |
| 中 | 各模块背景、卡片、渐变和装饰强度接近 | 页面缺少阅读节奏 | 白色主区域、浅色任务卡片、克制的蓝色 CTA；统一间距和边框 |

## 实施范围

- 仅中英文首页启用 `v3-refresh` 和新增样式；其他 13 种语言及内页保持原有设计。
- `home-copy.ts` 将本轮文案与原多语言默认文案隔离，避免修改英文回退影响其他语言。
- 中英文首页详细展示优先保留有实机证据的截图、标注、文字提取三个模块。贴图与录屏仍保留任务卡片，未删除软件功能或网站其他路由。
- 新素材为 `tools/capture` 中已有真实原图的完整副本，保留在 `src/assets/images/real/*-full.zh-cn.png`。未生成或修补软件 UI。
- 首图优先加载；预览按钮支持键盘、焦点轮廓和按下状态；图片 alt 随预览内容同步。
- 只预加载当前可切换的两张实机图，避免为未展示的旧渲染图请求资源。
- 页眉下载按钮及页脚介绍在中英文首页使用中性文案，避免沿用未经核实的免费和全本地承诺。

## 仍需完善的素材与内容

1. 真实截图仍有较大壁纸面积，原图包含任务栏和辅助提示。下一轮应重新取景，用更有意义的示例内容进行演示，减少无信息的壁纸面积；不要重新裁掉产品工具栏。
2. OCR 示例包含编辑器工具栏文本和额外悬浮贴图，尚不是理想的推广示例。后续应重新准备简短整洁的中英文示例，展示更清楚的识别结果。
3. 缺少英文软件 UI、贴图对照、滚动截图、录屏/GIF 的高质量实机素材；完成后可增加详细模块。不要用旧概念图填充成“真实截图”。
4. `docs/terminology.md` 仍引用旧产品路径、模型和宣传口径，应在独立的功能事实核实中更新，不能仅凭本次视觉改造确认其事实正确。
5. 版本页、FAQ、About 等内页仍有旧口径，商店和下载渠道也需全站核实。本轮没有改写整个站点或猜造有效链接。
6. Release 查询在本次构建环境失败，下载按钮使用项目已有的 GitHub Releases 回退，不代表已确认真实发行文件存在。
