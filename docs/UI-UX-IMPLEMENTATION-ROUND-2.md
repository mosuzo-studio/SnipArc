## 下载状态与后续配置

现有代码的 GitHub Releases 解析只依据 tag 拼装安装包文件名，并未校验资源存在。本次构建中 `/mosuzo-studio/SnipArc/releases/latest` 返回 404；连接的 GitHub 仓库查询也未能确认资源存在或拥有访问权限。这不能证明仓库不存在，但不足以把它当作已确认的公开下载入口。

因此中英文网站不再输出该失效发行链接；下载页明确显示“公开下载链接待提供”，并提供联系入口和下载包类型说明。

`src/data/sniparc-distribution.ts` 中的 `PUBLIC_RELEASES_URL` 是新的集中配置点。取得所有者确认且可公开访问的真实地址后再填写，不能猜造地址或安装包文件名。以后如果要提供直接下载，还需验证具体发行资产。

其他 13 种语言按原有范围保留，仍有历史文案和下载解析行为，未对其做事实同步或重新翻译。法律文件正文也未作新的法律承诺。
