## SnipX v7.20.8

**Released:** 2026-11-16

Initial public website release of SnipX. Features and interface reflect the current runnable version.

SnipX is a native Windows screenshot tool with region capture, annotation, clipboard workflow, global hotkeys, and on-device AI for OCR, background removal, and object erase.

**🚀 Core Features**

- Screenshot capture with system-native overlay
- Real-time selection and annotation tools
- Clipboard integration for quick sharing
- Global hotkeys for instant access
- Portable distribution (no installation required)

**🤖 Local AI Features**

- Offline OCR (PP-OCRv6 model)
- AI background removal (U2Net)
- AI object erase (MIGAN v2)

All AI processing runs locally on your device.
